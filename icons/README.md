# Extension Icons

The Bifurc icon (02 split path) in the sizes the manifest names:
- `icon16.png` — 16x16px (favicon, context menus)
- `icon32.png` — 32x32px (Windows toolbar at 200%, the extensions menu)
- `icon48.png` — 48x48px (extension management page, popup header)
- `icon128.png` — 128x128px (Chrome Web Store, install dialog): 96px art with 16px padding

Generated by `creative-new/src/icons.py` in the workspace (`python icons.py --deploy` copies them here).
`icon.png` is an unused copy of `icon128.png`.
