Allow Bifurc in private windows

Firefox only lets an extension set the proxy once it is allowed in private windows. The proxy stays off until you allow it:

  1. Open Add-ons and themes (Ctrl+Shift+A).
  2. Under Extensions, select Bifurc Companion.
  3. Set Run in Private Windows to Allow.
